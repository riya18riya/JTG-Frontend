# JTG Frontend Project

This project is a frontend development assignment based on a Figma design provided by our instructor.

The website has been recreated using HTML, CSS, and JavaScript while following the given design layout and structure.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Sections
- Navigation Bar
- Header / Hero Section
- Projects
- Recommendations
- Contact Information
- Footer

## Project Structure
- `index.html` – Website structure
- `css/style.css` – Website styling
- `js/script.js` – JavaScript functionality
- `images/` – Project images and assets

## How to Run
1. Download or clone this repository.
2. Open the folder in VS Code.
3. Run `index.html` using Live Server.

## Purpose
This project was created as part of a frontend development assignment to practice implementing a Figma design using web technologies.
